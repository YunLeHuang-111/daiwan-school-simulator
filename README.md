# 呆丸升學模擬

使用 **Java 17+、HTML、CSS、原生 JavaScript** 的單人網站遊戲。沒有 npm、Maven 或外部套件依賴，也不需要資料庫。

## 在 VS Code 執行

1. 用 VS Code 開啟這個專案資料夾。
2. 確認已安裝 JDK 17 以上：在終端機輸入 `java -version`。
3. 在**專案根目錄**的終端機執行：

   ```sh
   java --source 17 src/Main.java
   ```

4. 瀏覽器開啟 **http://localhost:8080**。
5. 終端機按 `Ctrl+C` 停止。

也可在 VS Code 使用「終端機 → 執行工作 → 啟動呆丸升學模擬」。不要以 Live Server 或雙擊 `index.html` 啟動，因為批改與錄取判定需要 Java API。

若 8080 被占用，可改用 `java --source 17 src/Main.java 8081`，再開啟 http://localhost:8081 。請固定使用同一網址，因為不同連接埠的瀏覽器存檔各自獨立。

## 已實作流程

- 填寫暱稱，開始或接續本機進度。
- 從 38 題題庫中隨機抽出 18 題：國文、英文、數學、自然、社會、常識各三題。題型包含資訊安全、生活閱讀、科學觀察、藝術、音樂、合作與邏輯。
- 40～300 字寫作小任務、Java 批改、會考積分與逐題解析。
- 18 個改名的示範高中職校科，搜尋與篩選，最多五志願，順序調整、分發與續招。
- 高中職六學期、每學期三回合：三格生活行動、一個事件、平時／小考／段考成績、可自由配置的成長點。
- 六種基本能力與人緣、自信、運氣（0～100）、精力與壓力、各科熟練度、學習歷程。
- 18 個不重複的校園事件，99 位同校模擬同儕；高三上結束時計算前五學期的校排名。
- 學測選科與成績模擬、高三下準備、繁星／個申／分發三種簡化管道。
- 16 間虛構大學、80 個示範系組；繁星選一個、個申最多六個、分發最多五十個志願。
- 分科八科選考、錄取接受／放棄、準大學生或重考生結局、個別旅程評語、文字紀錄下載。
- 自動存檔與錯誤提示；考試、事件結算與成長點會一起儲存，重新整理不會重抽。
- 支援手機與鍵盤操作、減少動態效果偏好。

## 程式結構

```text
src/Main.java          Java 本機 HTTP 伺服器、題庫、會考批改、錄取判定
web/index.html         網頁入口與對話框
web/style.css          桌面／手機版面與校園視覺
web/app.js             遊戲狀態、養成流程、學校與校系資料、畫面互動
.vscode/tasks.json     VS Code 啟動工作
tests/smoke.py         Java API 與靜態資源檢查（Python 3）
tests/browser.cjs      完整流程與手機版面端對端檢查（選用 Playwright）
```

改題目：編輯 `Main.java` 的 `bank`，每行格式為：

```text
科目|題型|題目|選項A~選項B~選項C~選項D|正解索引0至3|解析
```

每科至少保留三題，文字不要包含分隔符號 `|` 或 `~`。題庫變動後需重啟 Java；若刪除或重排題目，請重新開始遊戲，避免舊存檔題號不符。

改高中職：編輯 `app.js` 的 `HIGH_SCHOOLS`。

改大學與科系：編輯 `UNIVERSITIES`、`DEPTS`、`PROGRAMS`。每校目前使用五個輪替的示範系組，**不是現實學校科系對照表**。

改事件：編輯 `EVENTS`。目前每輪有 18 回合，需要至少 18 個事件。

## 遊戲規則與目前範圍

這是一個可完整遊玩的原型，**不是正式升學落點工具，也沒有收錄全臺所有學校科系**。

- 會考各科以該科答對率85%＋常識答對率15%，線性換算並四捨五入為1～7積分；作文以結構特徵給1～6級分，再換成0～1積分。最高36分。短題組不能代表正式會考能力。
- 作文僅檢查長度、標點、因果／轉折詞與例證詞，**不判斷語意與文章品質**；規則於遊戲內公開。
- 高中職以遊戲門檻依志願順序錄取；尚未實作就學區、招生名額及同分比序。
- 成長點每回合3～7點；能力60／80／95以上，每加1點需2／3／5成長點，其餘1點。
- 學測、分科依養成狀態模擬，不另外出試題；分科由高三下成長與額外準備加成反映再次挑戰。
- 同校99位同儕的比較基準入學時固定生成，與玩家前15回合平均比較，排名為前1～100%。
- 繁星簡化為校排名資格＋單一校系推薦＋學測65%與排名35%綜合判定；本版沒有校內推薦競爭或學群規則。
- 個申簡化為學測檢定＋學測55%、學習歷程20%、自信10%、對應專長15%，依志願順序保留首個達標校系；沒有真實校系的分階段倍率篩選、面試、術科或候補程序。
- 分發簡化為所選分科的加權百分成績；第一採計科目權重2，其餘1。尚未混採學測、英聽或術科。**不使用學測15級分直接乘四假冒正式60級分換算。**
- 招生無其他考生名額競爭，各校系以明示門檻判定，非現行招生算法。
- 高中職皆可走本作一般大學升學路線；技專統測、技優、四技二專及特殊選才尚未加入。
- 六年國高中完整學程已依新構想改為「會考起點＋高中職三年」。

進度存在瀏覽器 `localStorage`，重新整理後於首頁點「繼續旅程」。不提供登入、雲端存檔、多人遊戲或防作弊；Java 負責題庫答案、會考批改及錄取公式，其餘養成與學測／分科模擬由前端執行。此架構適合學習與單人原型，不適合競技排行榜。

## 檢查

伺服器執行時可用：

```sh
python3 tests/smoke.py http://localhost:8080
```

開發環境如已安裝 Playwright 與 Chromium，可另執行 `node tests/browser.cjs`。使用已安裝的 Chrome 時，可在 macOS／Linux 設定 `TEST_BROWSER_CHANNEL=chrome node tests/browser.cjs`。這些測試工具不影響遊戲啟動，正常遊玩只需要 Java。

修改 Java 後需停止並重啟伺服器；修改 HTML／CSS／JS 後重新整理即可。網頁資源不快取，方便開發。
