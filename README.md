# 呆丸升學模擬

作者 **LeleHuang**。Java 17+、HTML、CSS與原生JavaScript的單人網站遊戲，從高中入學走到大學學生證。

## 分享給朋友玩

**[直接開始遊戲](https://yunlehuang-111.github.io/daiwan-school-simulator/)**

分享版是純瀏覽器遊戲，朋友開啟網站即可遊玩，不需安裝Java或登入帳號。玩家進度、照片與成就留在各自瀏覽器。

GitHub儲存庫：[YunLeHuang-111/daiwan-school-simulator](https://github.com/YunLeHuang-111/daiwan-school-simulator)。

建置靜態分享版：

```sh
python3 scripts/build_share.py --zip
python3 tests/share_package.py
python3 -m http.server 8090 --bind 127.0.0.1
```

開啟 <http://localhost:8090/dist/>。`dist/` 可託管於GitHub Pages等靜態網站；`release/daiwan-school-simulator-share.zip` 為分享版壓縮檔。GitHub Actions工作流程會在推送main／master時建置並部署；倉庫Settings → Pages的來源須設為GitHub Actions。

分享版使用與Java相同規則的瀏覽器引擎；Java版仍可供VS Code開發與測試。分享版的題庫與正解會下載至瀏覽器，屬單人遊戲，沒有競賽防作弊設計。

## 在 VS Code 啟動

從專案根目錄執行：

```sh
java --source 17 src/Main.java
```

瀏覽器開啟 <http://localhost:8080>。終端機按 `Ctrl+C` 停止。也可用VS Code「執行工作 → 啟動呆丸升學模擬」。不需要npm、Maven或資料庫。若8080已占用，可改用 `java --source 17 src/Main.java 8081`。

不要直接雙擊HTML或用Live Server：出題、批改及錄取判定需要Java。Java與題庫變更後重啟伺服器；前端與JSON變更後重新整理即可。

## 玩法

- 填寫姓名，選擇男生／女生與公立／私立高中，並選填旅程種子。直接分配50所普通高中之一，沒有會考或高職。相同種子、性別與公私立偏好分配相同高中及起始能力，各校有不同傾向，五項基礎總點數相同。女校只分給女生、男校只分給男生；高門檻學校的遊戲稀有度較高、抽選權重較低。五星／四星／三星／二星相對權重1／3／7／12，不代表真實年度會考分數或招生機率。
- 高中三年共六學期；每學期**兩題問答、一個事件、一輪骰子、一個小遊戲**。突發事件由系統敘述並套用能力變化。一般骰子1～6顆，慈修高中多1顆，每顆1～6點，逐顆分配到數理、語文、社會、藝術、音樂，上限100。
- 913道題目資料，包含影視、文法、定理公式、數學家、現代閱讀、文言文、臺灣常識、運動與時事。舊題保留以批改既有存檔。
- 23種小遊戲主題：動漫、大學縮寫、品牌色塊、名畫、影視演員、K-pop粉絲名配對；歌詞猜歌、歌名猜歌手、歌詞猜歌手；翻牌記憶、歷史排序、色感找不同、emoji猜電影。新增國旗色塊、柯南情報員配對與劇場版年表、哈利波特護法、麻將牌型及影集宇宙。另有房子疊疊樂、足球攻防、垃圾分類和校慶幸運袋。歌曲庫共54首。歌曲遊戲只保留歌詞猜歌名、歌名猜歌手、歌詞猜歌手。移除填空與事先歌手提示，錯誤選項優先使用同類型歌手／樂團作品，使選項更接近。每個配對／配合題四組；找不同為25格、連闖三題；翻牌先記憶再挑戰。技巧小遊戲兩次失誤即結束，失敗或跳過扣對應能力4點（不低於0）。幸運袋依抽中的獎勵計分。
- 高三上先計算暫定排名並參加學測，高三下完成後更新為最終排名。選管道前會顯示排名、成績與資質。
- 學測與分科**每個選考科目各三題**（英文為兩選擇、一配對；其他科為選擇、配對、短填答各一），不加入未選科目。學測全6科18題，分科全8科24題。配對按答對比例給分。學期兩題問答每題答對加對應能力2點、答錯扣3點：一對一錯同時有獎勵與扣分，全錯只有扣分；全對加4點。學測和分科答錯不扣能力，逐題提交後不能返回。限時選擇題答對按時間給 1～5 分，分科再換算成原有的 60 級分；配對與填答沿用原本判分。
- 50所諧音大學、538個可選填的科系，依文法商、理工、生命醫藥、音樂、美術影視、舞蹈、醫牙等遊戲類組分類。
- 繁星先選一校、再選一類組、最多三系；個申最多三系；分發最多十系。所有志願清單可選錄取率高到低、低到高或原始順序；繁星先選學校時依各校最高預估機會排序，進入類組後按個別科系機會排序。排序不改玩家已排好的志願序。依志願順序取首個錄取，繁星未錄取可改個申；分科只在繁星或個申放榜後提供，已錄取者須先確認放棄原錄取。起始管道只有繁星、個申。
- 學生證使用各校原創無英文校徽、配色與依角色性別顯示的人像頭貼。可自行上傳JPEG/PNG/WebP（10MB內），中心裁切後僅存於本機，可下載1520×960 PNG。
- 準大學生或重考生結局，提供畢業評語、旅程紀錄與300個隱藏成就。每局最多解鎖5個，成就跨旅程保留，並可按類別查看。

## 出題、成績與錄取

題目為人工分級，並非經統計校準的正式能力測驗。問答以三星為主；前兩學期對應能力低於45時優先二星，之後優先三星；學測／分科能力達75優先三星，數學A／甲優先三星。英文組卷為影視選擇、影視或基礎文法配對、文法選擇，最多二星且無短填答。數學優先抽定理、公式與數學家，數學 A／甲優先較高難度。英文作者題停抽。其他科沿用原難度。題庫不足則採最接近的難度。先避開見過的題號，用完才重複，同張考卷不重複。歌單及配對素材也記錄已見項目；固定題庫仍可能在長期遊玩後用完。

平時與小考由能力及歷程產生，學期綜合成績＝平時20%＋小考20%＋問答60%。在校成績以學期平均 85% 和起始資質 15% 計算，再與 99 位同校基準比較，得到前 1～100%。按「確認答案」立即公布結果及解析。一般科目限時 30 秒，以 5／8／10／15 秒為級分界線；數學限時 60 秒，以 8／15／20／30 秒為級分界線。答錯或超時得 0 分。其餘題型依原有難度分配該科剩餘的分數。短填答接受列出的別名、忽略英文大小寫與空白，支援全形數字。

每系考試分數：第一採計科目權重2，其餘1，換成百分制。科系資質＝對應五能力加權的「目前能力65%＋起始資質35%」。

| 管道 | 遊戲綜合分數 |
| --- | --- |
| 繁星 | 在校成績75%＋學測25%（台清交成政限前20%，中字輩限前30%） |
| 個申 | 學測40%＋科系資質30%＋面試30% |
| 分發 | 考試70%＋科系資質30% |

三所藝術大學的個申使用上表共同公式，分發採藝術／音樂資質 75%、考試 25%。科系可調配藝術與音樂的比重。繁星使用上表的在校成績與學測權重。

綜合分數以邏輯斯曲線對照遊戲門檻。難度由高到低依序為醫牙藥、台清交成政、中字輩電資、中字輩其他、其他國立、私立電資、私立其他。參考分數用於同層校系之間的微調。錄取抽選固定於「旅程種子＋管道＋校系」。前端預估和 Java 使用相同公式，Java 也驗證志願數、繁星單校單組、採計科目與分數範圍。

這是遊戲招生模型；類組、採計、門檻與機會**不是任何年度招生簡章**。尚未模擬真實名額競爭、候補、術科、面試、各種身分與完整推薦程序，也未收錄全臺所有大學。真實設系對照與新聞來源見 [docs/SOURCES.md](docs/SOURCES.md)。素材來源見 [docs/ASSETS.md](docs/ASSETS.md)。

## 程式與資料

```text
src/Main.java          本機HTTP伺服器、種子分校、出題批改、錄取
web/app.js             六學期狀態與互動、成就、自製選單、Canvas學生證
web/runtime.js         靜態分享版的種子分校、出題批改與錄取引擎
scripts/build_share.py 產生可部署dist/與ZIP
web/index.html         首頁框架與對話框
web/style.css          校園風格與手機版
web/catalog.json       50所大學、538個可選填系組、採計與遊戲門檻
web/events.json        12個事件，每個三種選擇
web/minigames.json     23個小遊戲主題
web/songs.json         32首歌名、歌手、選項分組與極短歌詞片段
web/assets/            校園插畫、100個原創校徽、6場景、人像
data/questions.tsv    661題（含152道停抽舊題），開發版Java批改，分享版瀏覽器批改
data/schools.tsv      50所普通高中起始能力
data/programs.tsv     與catalog對應的Java招生規則
tests/smoke.py        API與資料驗證（Python標準函式庫）
tests/browser.cjs     瀏覽器流程驗證（選用Playwright與Chrome）
```

題庫每行10欄，UTF-8，以 `|` 分隔：

```text
id|科目|難度1至3|主題|choice/match/fill|題幹|左欄~分隔|選項~分隔|正解|解析
```

choice：四選項、正解0～3。match：左右各四項，正解如`1,2,0,3`。fill：左右欄填`-`，正解可用`/`列別名。ID要唯一且穩定，題幹勿含直線分隔符；英文不含填答；其他科應保留足夠三題型。修改校系規則時須同步JSON與TSV；新聞應寫明年份與查核日期。

## 存檔與驗證

旅程使用 `daiwan-campus-v5`，舊v1／v2／v3／v4旅程紀錄保留，不轉換；已解鎖成就沿用同一成就收藏。這次小幅更新維持v5旅程格式，可繼續；新抽試卷採新規則，已結局旅程會補判可追溯的新成就一次。重整後按「繼續我的旅程」。照片、成就與已見題目分別存於此瀏覽器；清除網站資料會刪除所有紀錄，不會上傳雲端。請固定使用相同主機與連接埠。這是本機單人原型，沒有帳號、多人、防作弊或自動新聞更新。

Java執行時：

```sh
python3 tests/smoke.py http://localhost:8080
TEST_BROWSER_CHANNEL=chrome node tests/browser.cjs
```

第二項需事先安裝Playwright，可使用既有Chrome。驗證涵蓋六學期、事件取捨、骰子續存、23種小遊戲、全部選科題數、三管道限制、資質機會、選單鍵盤操作、照片與PNG匯出、兩種結局、隱藏成就與手機版。

分享版驗證另有 `node tests/runtime-parity.cjs`（Java執行時，比對兩個引擎），以及 `TEST_URL=http://localhost:8090/dist/ node tests/browser.cjs`（靜態伺服器執行時）。分享版在子目錄路徑也須能完整遊玩。

## 志願清單與校系圖鑑

手機／平板版先顯示志願清單，提交按鈕在清單頂端；選好科系後，也可用底部「查看與提交」快捷鍵回到清單。依大學篩選可搭配錄取率排序，不影響已排好的志願序。

頁面頂端「校系圖鑑」可查看已解鎖大學、科系、首次錄取日期與管道，先列出所有大學，點開校名即可看見亮色的已解鎖科系與灰色的未解鎖科系。只有接受錄取才解鎖；未接受的放榜結果與重考結局不會新增校系。收藏另存於 `daiwan-university-collection-v1`，重新開始旅程會保留。更新時可補入目前存檔已接受的錄取，已被覆蓋的舊旅程無法回溯。收藏只保存在目前瀏覽器，清除網站資料也會清除收藏。

收藏頁可直接開啟 `#collection`，返回遊戲會保留原本進度。新增互動驗證：`TEST_URL=http://localhost:8090/dist/ node tests/collections.cjs`（需Playwright與Chrome）。


院校資料取教育部 114 學年度日間學士與四技名冊。可選填的技專校院保留台科、北科、虎尾、雲科及嘉南藥理，移出校系的已錄取紀念與收藏以歷屆紀錄保存。學校名稱與校徽均為遊戲自製。四技仍沿用遊戲原有的升學管道，現實中普通高中生另有四技申請等制度。

錄取門檻參考 [115 學年度大學分發最低錄取標準](https://www2.uac.edu.tw/115data/115_result_school_data.pdf) 和 [115 學年度四技二專聯登錄取分數](https://www.jctv.ntut.edu.tw/downloads/115/union42/115_up01.pdf)。先用各筆加權滿分換算成比例。一般學科以 60、術科與統測以 100 為各科上限，再分管道計算相對位置。相同校系多筆結果取中位數，缺該系資料時採同校中位數，兩者都沒有則取難度層級中央值。此相對位置只調整同一層內的遊戲門檻，不跨越玩家指定的難度順序。資料已存於 `web/catalog.json` 的 `admissionReference`，志願卡片可展開官方來源。


個人申請先以學測篩選，21 個校系參考 115 學年度官方一階資料折算；其餘依原有校系難度估算。遊戲採計科目和現實篩選關卡可能不同。通過一階後玩三關面試小遊戲，包含房子疊疊樂、足球攻防和垃圾分類。各校系對三關的表現給不同權重。若所有已考學測科目皆滿級分，完成面試後原志願仍全落榜，系統會在有符合採計科目的普通校系時提供備用錄取。


學期問答輪替台灣趣聞、世界地標、城市、企業、影視、歌曲、動漫、運動等題材。抽題優先避開本局已出現的類別，再參考此瀏覽器近 72 題的出題紀錄，優先抽最近較少見的類別。每局六個課間小遊戲優先選不同玩法，並依最近遊玩紀錄輪替。麻將問答與麻將小遊戲只在不同的少數種子出現。志願清單可按住把手拖曳排序，也支援方向鍵。可從頁首「風格」切換校園、美式復古或港風，設定儲存在此瀏覽器。


學測英文配合題以基礎文法、影視詞彙與熟悉的劇情線索為主。國文配合題以現代閱讀為主，數學優先抽定理、公式與數學家題，自然與社會保留進階配合題。學測原始級分再依該科起始資質（65%）與目前能力（35%）最多調整 1 級分，額外加分最高到 14，原始零分仍為零。個申放榜即結束此管道。台清交成政的非醫牙藥科系，會依高學測分數、科系資質和面試表現逐步調高個申錄取機會，最高仍為 45%。
